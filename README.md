# Samuel Waltrich - Portfolio Pessoal

Um website profissional e moderno com tema dark/cyberpunk, perfeito para apresentar seu trabalho como desenvolvedor front-end.

## 🎨 Características

- **Design Dark & Moderno**: Tema cyberpunk com cores neon (verde e cyan)
- **Totalmente Responsivo**: Funciona perfeitamente em desktop, tablet e mobile
- **Animações Elegantes**: Efeitos suaves e profissionais em toda a página
- **Otimizado para SEO**: Meta tags, Open Graph e estrutura semântica
- **Alta Performance**: Código otimizado e sem dependências externas
- **Acessibilidade**: Segue boas práticas de acessibilidade web
- **Interatividade**: Efeito typewriter, scroll reveal, smooth scroll e mais

## 📁 Estrutura de Arquivos

```
samuel-portfolio/
├── index.html          # Arquivo HTML principal
├── css/
│   └── style.css       # Estilos completos (dark theme)
├── js/
│   └── script.js       # Interatividade e animações
├── images/             # Pasta para imagens (vazia por padrão)
├── assets/             # Pasta para outros assets
└── README.md           # Este arquivo
```

## 🚀 Como Usar

### Opção 1: Abrir Localmente
1. Extraia o arquivo ZIP
2. Abra o arquivo `index.html` no seu navegador
3. Pronto! O site está funcionando

### Opção 2: Fazer Deploy
1. Faça upload de todos os arquivos para seu servidor web
2. Certifique-se de manter a estrutura de pastas
3. Acesse o domínio no navegador

### Opção 3: GitHub Pages
1. Crie um repositório no GitHub
2. Faça upload dos arquivos
3. Ative GitHub Pages nas configurações
4. Seu site estará disponível em `https://seu-usuario.github.io/seu-repositorio`

## 🎯 Seções da Página

- **Hero**: Apresentação inicial com terminal interativo

## 🎨 Personalização

### Cores
Edite as variáveis CSS em `css/style.css` (linhas 1-20):

```css
:root {
    --accent-primary: #00ff41;      /* Verde neon */
    --accent-secondary: #00d4ff;    /* Cyan neon */
    --accent-tertiary: #ff006e;     /* Rosa neon */
    /* ... outras cores */
}
```

### Conteúdo
Edite o arquivo `index.html` para:
- Alterar seu nome e profissão
- Atualizar sua bio
- Adicionar/remover habilidades
- Modificar links de redes sociais
- Adicionar seus projetos

### Tipografia
Altere a fonte em `css/style.css`:

```css
--font-primary: 'Sua Fonte', sans-serif;
--font-mono: 'Sua Fonte Monoespacial', monospace;
```

## 📧 Formulário de Contato

O formulário está configurado para:
- Validar campos obrigatórios
- Validar formato de email
- Mostrar mensagens de sucesso/erro
- Limpar o formulário após envio

**Nota**: Por padrão, o formulário não envia dados para nenhum servidor. Para ativar o envio real, você precisará:

1. Configurar um backend (Node.js, PHP, Python, etc.)
2. Usar um serviço como Formspree, EmailJS ou Netlify Forms
3. Atualizar o código JavaScript em `js/script.js`
